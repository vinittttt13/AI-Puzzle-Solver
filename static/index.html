Artificial Intelligence Theory & Viva Comprehensive Guide

Academic reference material covering state spaces, heuristics admissibility, and oral exam prep.

1. Formal State Space Problem Formulation

  • State Representation: A permutation of $\{0, 1, \dots, N^2 - 1\}$, where $0$ represents the blank tile.
  • Initial State: Any arbitrary valid configuration of tiles.
  • Actions: Move blank $\in \{\text{UP}, \text{DOWN}, \text{LEFT}, \text{RIGHT}\}$ if within grid boundaries.
  • Transition Model: Swaps the blank tile with the adjacent tile in the designated direction.
  • Goal Test: Checks if current board matches the target ordered state $(1, 2, \dots, N^2-1, 0)$.
  • Path Cost: Each transition has uniform unit cost $c(n, a, n') = 1$. Total cost = number of moves.
  • State Space Size: For 8-puzzle: $\frac{9!}{2} = 181,440$ reachable states. For 15-puzzle: $\frac{16!}{2} \approx 10^{13}$ states.

2. Mathematical Solvability (Inversion Theorem)

Not every random permutation is solvable. Exactly 50% of all configurations are unreachable!

Definition: An inversion is a pair of tiles $(a, b)$ such that $a > b$ and $a$ appears before $b$ in linear order (ignoring blank $0$).
  • Odd Grid Width (3x3): Horizontal moves don't change inversions. Vertical moves change inversions by an even number ($-2, 0, +2$). Parity is invariant. Therefore, a 3x3 state is solvable iff inversion count is EVEN.
  • Even Grid Width (4x4): Vertical moves change inversions by an odd number. Hence: (inversions + blank_row_from_bottom) % 2 == 1.

3. Heuristics & Admissibility Criteria

  • Admissibility: $h(n) \le h^*(n)$ for all $n$, where $h^*(n)$ is the true shortest distance to goal. Guarantees A* finds an optimal solution!
  • Consistency (Monotonicity): $h(n) \le c(n, a, n') + h(n')$. Triangle inequality. Guarantees that the first time A* expands a state, its path is already optimal (no reopenings needed).
  • $h_1$ Misplaced Tiles: Counts misplaced tiles. $h_1(n) \le h^*(n)$. Admissible.
  • $h_2$ Manhattan Distance: Sum of grid distances. $h_2(n) \ge h_1(n)$ and $h_2(n) \le h^*(n)$. Strictly dominates $h_1$.
  • $h_3$ Linear Conflict: $h_{\text{LC}} = h_2 + 2 \times \text{conflicts}$. Two tiles in the correct row/col that must cross each other require at least 2 extra moves. Admissible and strictly dominates Manhattan!

5. Top 5 Viva Questions & Answers

Q1: Why does A* search guarantee an optimal solution?

A* explores states ordered by $f(n) = g(n) + h(n)$. When $h(n)$ is admissible (never overestimates true cost), any goal node popped from the frontier has a cost less than or equal to any unexpanded node on the frontier. Therefore, the first time the goal is popped, its path cost is guaranteed minimal.

Q2: What is the difference between heuristic Admissibility and Consistency?

Admissibility requires $h(n) \le h^*(n)$. Consistency (monotonicity) requires $h(n) \le c(n, a, n') + h(n')$, which is the triangle inequality. Consistency implies admissibility. Under a consistent heuristic, $f(n)$ values along any path are monotonically non-decreasing, guaranteeing that every node expanded by A* has an optimal $g$-score without needing to reopen nodes.

Q3: What is the Linear Conflict heuristic and why is it admissible?

A linear conflict occurs when two tiles $t_j$ and $t_k$ are in their goal line (row or column), but $t_j$ is placed in front of $t_k$ while its goal is behind $t_k$'s goal. Since tiles cannot jump over each other, one tile must leave that row/column and re-enter, which mathematically requires at least 2 extra moves not accounted for in standard Manhattan distance. Hence, $h_{\text{LC}}(n) = h_{\text{Manhattan}}(n) + 2 \times \text{conflicts} \le h^*(n)$.

Q4: Why does BFS struggle with Hard 8-puzzle instances while IDA* succeeds?

BFS keeps all generated states in memory (queue). With an average branching factor $b \approx 3$, at depth $d = 20$, the frontier contains up to $3^{20} \approx 3.4 \times 10^9$ states, quickly causing Out-Of-Memory (OOM) errors. In contrast, IDA* uses depth-first iterations with an $f$-bound cutoff, consuming only $O(d)$ memory (proportional to depth).

Q5: Can any 8-puzzle configuration be transformed into any other?

No. The state space of the 8-puzzle is partitioned into two mutually disconnected components of $181,440$ states each ($\frac{9!}{2}$). Legal tile moves preserve the parity of the permutation's inversion count. Therefore, a state with an odd number of inversions can never reach the standard goal state (which has 0 inversions, an even number).
